專案背景與痛點分析

新手帶班困境

大領班與專員多為新手，缺乏經驗與權威，難以有效管理產線品質。

RBA 合規限制

受 RBA（負責任商業聯盟）規範，無法使用辱罵、威脅、扣薪等粗暴管理方式。

NG 件過多

螺絲未鎖確實、零件漏裝等問題頻繁，導致重工成本增加與交期延遲。

管理對立

傳統「要求/罵人」模式引發 OP 反感，隱瞞 NG 件情況時有發生。

低成本優化方案

01

螺絲定量盤

每個工站放置定量盤，備料時放入正確數量螺絲。組裝完畢後，盤內剩餘螺絲 = 漏鎖，OP 自行發現。

成本：極低（紙盒）
02

油漆筆標記

鎖完螺絲後用油漆筆在螺絲頭畫點，後站一眼可見是否已鎖，責任明確。

成本：極低（麥克筆）
03

壓克力遮罩板

製作孔位遮罩板，只露本工站需鎖的孔位，防止新手 OP 找錯孔位或忘記孔位。

成本：低（壓克力板）
04

雙人互檢機制

下站 OP 接過機殼時，先快速掃視上站關鍵螺絲與組裝件，發現錯誤可得品貼集點獎勵。

成本：無成本（流程調整）
05

視覺化 SOP

工作檯正面貼上特大號彩色圖卡，標明螺絲數量與鎖附順序，OP 一眼看懂。

成本：低（彩色列印）
06

低衝突管理法

領班用 CheckList 代替口頭訓斥，以「協助發現問題」角度溝通，符合 RBA 規範。

成本：無成本（流程調整）

📐 品質評分公式

每台 AI 伺服器組裝完成後，依以下維度進行評分（滿分 100 分倒扣制）：

品質分數 = 100 - (螺絲扣分 + 油漆點扣分 + 卡榫扣分 + 互檢扣分)
評分維度正常條件異常扣分
螺絲到位定量盤空 + 實際鎖附數 = 規定數-25 分/顆
油漆點標記每顆螺絲頭均有標記-10 分/顆
卡榫到位PSU/風扇卡榫 Click 聲確認-20 分/項
下站互檢下站 OP 簽章確認-15 分

🏆 品質等級門檻

依據最終品質分數，劃分三大等級：

等級分數區間處置方式
PASS90 ~ 100 分直接過站，無需複檢
WARN70 ~ 89 分標記待確認，下站加強互檢
FAIL0 ~ 69 分拉停線 (Andon)，現場重工後複檢

1. FPY（首次通過率）

整體 FPY = PASS 數 ÷ 總台數 × 100%

例：77 PASS ÷ 100 台 = 77.0%

各線 FPY = 該線 PASS 數 ÷ 該線總台數 × 100%

各工站 FPY = 該工站 PASS 數 ÷ 該工站總台數 × 100%

資料來源：xlsx 欄位 [11]（Result），PASS = 通過，其他為 NG

2. Pareto 圖（NG 類型帕累托）

X 軸：NG 類型（按次數降序排列）

左 Y 軸：各 NG 類型出現次數

右 Y 軸（累計%） = (累計次數 ÷ NG 總次數) × 100%

例：螺絲缺失 8 次、漏鎖 6 次、NG 總 23 次 → 螺絲缺失累計 34.8%、漏鎖累計 60.9%

資料來源：xlsx 欄位 [13]（NG Type）

3. 各線 FPY 比較（Bar Chart）

FPY % = 該線 PASS 數 ÷ 該線總台數 × 100%

資料來源：xlsx 欄位 [4]（Line）、[11]（Result）

4. NG 類型分佈（Doughnut）

計算各 NG 類型出現次數，以圓餅圖顯示比例

例：螺絲缺失 8、漏鎖 6、外觀刮傷 4、...共 10 種類型

資料來源：xlsx 欄位 [13]（NG Type），僅統計 result ≠ PASS 且 ngType ≠ "-" 的記錄

5. NG 發現者分佈（Doughnut）

計算各作業員透過雙人互檢發現 NG 的次數

資料來源：xlsx 欄位 [16]（Peer Finder），僅統計 result ≠ PASS 且 peerFinder ≠ "-" 的記錄

6. 獎勵排行榜（Horizontal Bar）

依各作業員 PASS 數量排序，顯示前 8 名

資料來源：xlsx 欄位 [12]（Operator）、[11]（Result）

7. 每日 FPY 趨勢（Line Chart）

每日 FPY % = 當日 PASS 數 ÷ 當日總台數 × 100%

例：8/11 → 10 PASS / 14 台 = 71.4%

資料來源：xlsx 欄位 [2]（Date）、[11]（Result）

8. 各線每日 NG 數趨勢（Multi-Line）

每日各線的 NG 數量折線圖

資料來源：xlsx 欄位 [2]（Date）、[4]（Line）、[11]（Result），result ≠ PASS 即計為 NG

9. MVP 每週 FPY 趨勢（Line Chart）

週平均 FPY = 該週所有記錄的 FPY 平均值

例：Week 1 有 5 筆記錄，FPY 分別為 92、88、95、90、87 → 平均 90.4%

總 PASS：Result = PASS 的記錄數

總 NG：Result ≠ PASS 的記錄數

NG 率 = NG 數 ÷ 總台數 × 100%

各線 FPY = 該線 PASS 數 ÷ 該線總台數 × 100%

各工站 FPY = 該工站 PASS 數 ÷ 該工站總台數 × 100%

UID 去重邏輯：相同 UID 僅取最後一條記錄

色彩指示標準

● 綠色（優良）：FPY ≥ 95%

● 黃色（警示）：FPY ≥ 90% 且 ＜ 95%

● 紅色（異常）：FPY ＜ 90%
