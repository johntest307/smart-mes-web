# User Manual - Smart MES Platform

## 1. Splash Screen

Full-screen intro video (Zero.mp4) with audio. Click **ENTER** to proceed. Voice intro plays if enabled.

## 2. Home Page

Three sections:
- **Hero**: Animated KPI counters (Products, Lines, Yield, Uptime)
- **Smart Factory Panorama** (智慧工廠全景): 6 auto-playing demo videos. Click to enlarge: video left (with sound) + STAR content right (Situation/Task/Action/Result) with module icon and title

## 3. Process Showcase (流程展示)

9 chapter demo videos (V0-V8):

| Chapter | Topic |
|---------|-------|
| V0 | Registration / Kitting |
| V1 | Product Vision |
| V2 | Server Assembly |
| V3 | CPU & Heatsink |
| V4 | RAM & Mezzanine |
| V5 | GPU Assembly |
| V6 | Add-on Cards & Network Modules |
| V7 | System Integration Test |
| V8 | Packing & Shipping |

**Auto-play**: First video muted. After manual play, subsequent videos auto-play. **Spacebar** toggles all. Voice reads titles if ON.

## 4. Dashboard

- Skill heatmap (23h x 60d), KPI cards, station grid, alerts, event log. Mock data updates periodically.

## 5. Monitor

- Station grid (20 cards), alert panel (critical/warning/info), event log.

## 6. Yield Analysis

- 4 KPI cards, production progress bar, defect Pareto + pie, yield + torque trends, station defect rate.

## 7. Guide

- Pillar cards + module explainers (problem/solution/benefits).

## 8. Navbar

- 6 links (Home, Process Showcase, Dashboard, Monitor, Yield Analysis, Guide) + lang selector + voice toggle. Logo is CSS background-image (no flash on lang switch).
